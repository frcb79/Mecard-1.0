# Skill: Design System — meCard

## Objetivo

Mantener consistencia visual y de interacción mediante componentes reutilizables, accesibles y orientados a flujos de negocio.

## Cuándo consultar este skill

- Al crear o modificar componentes base.
- Al redefinir patrones visuales de páginas de alto uso.
- Al introducir nuevas variantes de UI por rol.

## Principios del sistema de diseño

- Reutilización antes que duplicación.
- Claridad de estado: normal, loading, success, warning, error.
- Consistencia tipográfica, spacing y jerarquía visual.
- Componentes orientados a tareas reales del producto.

## Checkpoints por componente

- [ ] API del componente simple y tipada.
- [ ] Soporte de variantes y estados principales.
- [ ] Accesibilidad base (teclado, foco, labels) validada.
- [ ] Tokens/estilos reutilizables en lugar de estilos inline repetidos.
- [ ] Test de render e interacción para componentes críticos.

## Patrones de alta prioridad

- Formularios de monto y validación.
- Tablas/listas con filtros por rol.
- Tarjetas de saldo, transacciones y rewards.
- Notificaciones y feedback transaccional.
