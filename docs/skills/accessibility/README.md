# Skill: Accessibility — meCard

## Objetivo

Asegurar accesibilidad WCAG 2.1 AA en flujos críticos para estudiantes, padres y personal escolar.

## Cuándo consultar este skill

- Al crear formularios, navegación, modales o tablas.
- Al modificar estructura visual o jerarquía de contenido.
- Al implementar componentes reutilizables.

## Criterios mínimos WCAG 2.1 AA

- Contraste suficiente en texto y controles.
- Navegación completa por teclado.
- Estados de foco visibles y consistentes.
- Labels y nombres accesibles en inputs/botones.
- Mensajes de error asociados al campo correspondiente.
- Soporte para lectores de pantalla en acciones críticas.

## Checkpoints por PR

- [ ] Se puede completar flujo principal solo con teclado.
- [ ] No hay controles sin nombre accesible.
- [ ] Los errores de formulario son comprensibles y anunciables.
- [ ] No hay dependencia exclusiva de color para transmitir estado.
- [ ] Componentes de alto uso revisados con reglas de accesibilidad.

## Flujos prioritarios

- Login y recuperación de acceso.
- Recarga de saldo.
- Checkout POS.
- Canje de recompensas.
- Gestión de límites y permisos parentales.
